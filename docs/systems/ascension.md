# Ascension System

The Ascension System allows players to push equipment beyond normal upgrade limits.

## Goals

- Long-term progression
- Rare resource sink
- Build specialization
- Endgame scaling

## Planned Rules

- Ascension levels: 0 -> 10
- Failure chance at higher tiers
- Resource consumption per attempt
- Visual aura evolution
- Stat multiplier scaling

## Future Features

- Ascension simulator
- Probability calculator
- Upgrade cost estimator
- Build planner integration
